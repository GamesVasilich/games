How to host server (Instruction):

  1. Download and install Node.js from the official website (nodejs.org).
  2. Download the server archive using the "Download server" button above and unpack it into a folder.
  3. Open your command line / terminal (cmd) and navigate to the server folder using the command:
    cd path_to_your_folder
  4. Install the required packages by typing the command:
    npm install
  5. To start the server, just run the pre-made start.bat file inside the server folder. It will automatically enter the launch command for you.
  6. The server will open port 1000. Make sure this port is open on your router if you want to play over the internet, or just use your local IP address for LAN play.
